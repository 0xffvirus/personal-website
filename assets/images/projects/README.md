To replace an image, keep the same filename or update the matching `src` in **both** `index.html` (Arabic, the default) and `en.html` (English), then replace the alt text with a short description of the image in each language. The browser does not automatically discover new filenames.

Use 4:3 images, ideally 800×600 or 1600×1200. Keep important content away from the bottom edge, where the project title appears over a gradient. No project screenshots have been fabricated or taken from other websites.
